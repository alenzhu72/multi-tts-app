# SRT 多角色系统配音助手

这是一个本地网页工具，用来把 SRT 字幕自动初分成多个人物，并把识别到的人物合并映射到有限数量的系统声音角色。

## 使用方式

只做人物识别、角色调整、浏览器试听和导出标记 SRT 时，可以直接用浏览器打开 `index.html`。

如果要读取 Windows 系统声音并导出逐句 WAV 包，请在本目录启动本地服务：

```powershell
python server.py
```

然后访问 `http://127.0.0.1:5173`。

## 能做什么

- 导入或粘贴 SRT。
- 优先识别 `[speaker1]`、`[spk2]`、`人物名：台词` 这类已有说话人标记。
- 对没有标记的 SRT，使用台词轮换和文本特征做自动初分。
- 把系统识别出的人物合并到 A、B、C 等有限声音角色。
- 为每个角色选择浏览器/系统可用声音，并逐句或连续试听。
- 导出 pyVideoTrans 可继续使用的 `[speaker1]` 标记版 SRT。
- 启动 `server.py` 后，可用 Windows 系统声音生成逐句 WAV，并打包下载。
- 导出 JSON 配置，保留人物、角色、声音和逐句分配结果。

## 重要说明

纯 SRT 通常不包含真实声纹信息，因此没有音频时无法真正判断“这句话是谁说的”。本工具做的是智能初分和快速校正。如果你需要声纹级别的说话人分离，需要输入原始音频/视频并接入 ASR diarization 模型。
